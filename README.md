# 🚀 CRUD Flask + SQL Server (Dockerizado)

Este proyecto es una aplicación web funcional desarrollada con **Flask** para el backend y **Microsoft SQL Server** como base de datos. La interfaz está estilizada con **Tailwind CSS v4** y cuenta con animaciones personalizadas.

Lo mejor de este proyecto es que está totalmente **dockerizado**, lo que significa que se puede ejecutar en cualquier ordenador sin necesidad de instalar Python o SQL Server localmente.

---

## 🛠️ Tecnologías utilizadas

- **Backend:** Python + Flask
- **Base de Datos:** Microsoft SQL Server 2022
- **Frontend:** HTML5, Jinja2, Tailwind CSS v4, Animations.css
- **Contenedores:** Docker & Docker Compose

---

## 🚀 Cómo ejecutar el proyecto (Recomendado)

La forma más sencilla de revisar este proyecto es usando **Docker**.

### Requisitos:
1. Tener instalado [Docker Desktop](https://www.docker.com/products/docker-desktop/).

### Pasos:
1. Clona este repositorio.
2. Abre una terminal en la carpeta del proyecto.
